# 11/28 · 投下一次

極簡的台灣地方選舉投票練習。選擇選區、領取選票、自由蓋章，再投入票箱。

## 開始玩

[進入模擬投票](https://iiilun.github.io/vote-1128/)

圈選僅存在於目前的瀏覽器畫面；回到首頁即清除，不傳送、不儲存、不統計支持度。

## 資料與呈現

- 候選名單、號次、政黨、選區與可用照片：中選會 [2026 選舉資訊](https://info.cec.gov.tw/vote2026/)，2026/11/24 匯入。涵蓋 22 縣市及 2,028 張候選人照片。缺漏的票種標示待補，不補造候選人。
- 選票欄位參考[正式選舉公報](https://eebulletin.cec.gov.tw/)。此為互動模擬，比例、顏色及部分照片不等同實際選票；蓋章位置不限，不據此判斷法律上的有效票。
- 每組練習票加入全國性第 22 案公投。正式公投的投票資格仍以年齡與居住等法定條件為準。
- 結果頁投票率為 2022 年全縣市的縣市長選舉投票率，並非 2026 年即時投票率。
- 民調為已查核的封關前公開調查快照。目前收錄 11 個地區，日期、來源與方法記錄於 `data/reports.json`；缺漏地區顯示未收錄。

## 本機預覽與部署

這是無需編譯的靜態網站。以靜態 HTTP 伺服器開啟儲存庫根目錄即可，例如 `python3 -m http.server 4173`。

GitHub Pages 從 `main` 分支的根目錄部署，更新此分支後會自動重新發布。所有資產與資料使用相對路徑。
